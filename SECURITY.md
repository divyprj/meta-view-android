# Security Policy

## Supported Versions

Only the latest production release of Meta View receives security patches and validation updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We prioritize the integrity and security of our users' devices and media. If you discover a security vulnerability, please follow responsible disclosure protocols:

1. **Do not** file a public GitHub issue.
2. Email your findings and reproduction steps to: `surajdivyansh104@gmail.com`.
3. Provide details including affected device hardware, Android version, and steps to reproduce.

We will review reports within 48 hours and coordinate fixes prior to public disclosure.
